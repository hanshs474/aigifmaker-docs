# AI GIF Maker docs

Turn text into animated GIFs with AI GIF Maker. Native GIF generation — no video conversion. Type what you want and download your GIF in about a minute.

Source of the API and SDK documentation for [AI GIF Maker](https://aigifmaker.ai/?utm_source=readthedocs&utm_medium=package), built with MkDocs for Read the Docs: quickstart, HTTP API, SDKs in ten languages and the MCP server. Create a key at https://aigifmaker.ai/settings/apikeys; credit packs are on the [pricing](https://aigifmaker.ai/pricing?utm_source=readthedocs&utm_medium=package) page.

```bash
pip install -r docs/requirements.txt
mkdocs serve           # preview
mkdocs build --strict  # what CI and Read the Docs run
```
